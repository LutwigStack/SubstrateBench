# SB-001: public four-bit memory reference benchmark

STATUS: implemented and independently reviewed; local commit validated.

Owner: `substratebench.benchmark.evaluate`. The runner owns task evaluation,
qualification, paired controls, visible call accounting, and durable result
publication. The selected memory alone owns predicted task history. Callback
purity and frozen weights are explicit caller obligations, not enforced facts.

Scope: installable standard-library Python package, known digital BinaryMemory
and EncodedMemory, current-observation/command controller boundary, the complete
gated-XOR finite domain, reproducible ordered sequences, interface-failure
censoring, normal/permutation/zero/reset controls, and exclusive atomic JSON.

Evidence used to design the harness: the lab's source-rule-causality,
source-memory-capability, source-memory-set-coverage, and
source-independent-cost-pilot studies. Calibration with eight SET anchors failed
preservation of other bits; exhaustive 128-operation qualification is therefore
required. The positive learned-source experiment preserved task ability, while
the earlier exact full-hidden-source behavior comparison failed. Both results
remain in the lab. No historical outcome or learned source checkpoint is imported
as a public reference result.

Promotion is a minimal rewrite of the stable task, memory-ownership boundary,
measurement rules, failure handling, and controls. It does not import lab modules,
absolute paths, snapshots, model binaries, raw runs, or internal acceptance gates.
The public sampler differs from the lab sampler. SB-002 corrects the original
compatibility claim: public command bytes end in gate/value, while Lab bytes end
in value/gate. Historical exclusions require original command arrays to regenerate
public IDs; digest-only Lab IDs cannot be converted. Declared excluded identities are checked on original
and transformed paired queries. Completeness of a user's training-ID list cannot
be independently established by this API.

Checks: complete finite task and SET laws, negative writer censoring, invalid
commands/source outputs, deterministic paired cases and transformed exclusions,
real free execution/ablations, concurrent exclusive artifact publication, an
installed-package CLI run from a different working directory, and a custom
callback example. Reference-run pass is a harness check, not new transfer evidence.

Out of scope: unknown-substrate identification, learned adapter fitting, the
original PUBLIC simulator, physical hardware, computation transfer, full-cost
pretraining advantage, leaderboard, biological tracks, and license selection.
