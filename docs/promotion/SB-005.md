# SB-005: scalar public memory adapter

This promotion adds one standard-library adapter for the existing eight-bit
`reset()`, `read()`, `set_bit(register, value)` interface. The caller supplies a
public `reset(lane, batch)`, `step(lane, stimulus)`, `observe(lane)` port and frozen
affine reader and pulse coefficients. Task computation remains in the existing
carry8 or conditional8 callback; the adapter receives no commands or task Gold.

The optional, installed `substratebench.public_memory8_demo` recipe generates its
own two-bank noiseless discrete-tanh simulator and fits its reader and pulses
from public observations. NumPy is required only by that recipe. Generated
coefficients, geometry, complete primitive and operation journals, reports, and
their checksum manifest remain outside Git. This is a newly paid reference run,
not a replay of inaccessible historical learned checkpoints.

Before code, the bounded intended claim is a known simulated continuous memory
storing eight logical task bits, with the exact task rule computed on the CPU.
No learned-source, hardware, arbitrary-family, Shannon-capacity, energy or cost
advantage claim is included. Old Lab batch-16/batch-128 results do not qualify
this scalar adapter. Software mocks prove contracts only. Candidate-specific
full scalar physical qualification and independent reconstruction are required
before describing this candidate as physically qualified.

READ always observes both banks anew. SET emits the selected-bank pulse and an
opposite-bank zero, observes both banks, and then emits eight zero ticks and a
fresh two-bank read: 22 primitive calls and nine common ticks. A word write is
eight separate SET operations, 176 calls and 72 ticks. Reset preserves the
reviewed bootstrap: two public resets, four simultaneous two-bank zero-bit
slots, and a final fresh read, totaling 84 calls and 44 common ticks. The stock
evaluator then performs its own eight SET initialization. `zero_write` skips
SET, so it is not a matched-time intervention.

The adapter owns frozen public coefficients, attempt/completion counters, and
failure status. The port owns authentic request identities, transport, raw
journaling, deadlines, and cleanup. The simulator owns private continuous state
and geometry. The task evaluator owns labels and logical-call costs. Arbitrary
Python callback purity and freezing remain caller obligations.

Inputs are bounded: coefficient JSON is at most 64 KiB, has exactly the declared
schema and 520 finite numeric coefficients, reader magnitude at most 1e6, and
pulses within [-1, 1]. Observations contain exactly one row of 32 finite numeric
values per bank. Invalid requests fail before port mutation. An interrupted or
malformed-response operation permanently breaks the adapter; no retry, cached
state, rollback, or label repair is performed.

The prospective minimum conformance runs both existing laws independently with
seed 42 and two episodes per length at L24/L128, all 256 READ and 4096 preserving
SET cases per law, all 8192 exact source cases, and all four own-state routes.
Separate retention diagnostics use 32 scalar SET and 64 public zero ticks.
L512, timed shams, noise, learned source coupling, and new benchmark laws are
outside this promotion. Exact execution and audit quotas, candidate hashes,
frame/storage limits, and actual results will be recorded before qualification.

The retention diagnostic covers one fixed 32-SET history, ending in all-one
state, followed by 64 idle ticks. It is not exhaustive retention over all 256
states. Reference reports keep their existing 0.3.0/0.4.0 contract versions;
the installed package advances to 0.5.0.
