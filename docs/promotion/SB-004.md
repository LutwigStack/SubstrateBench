# SB-004: bounded eight-bit conditional reference profile

STATUS: implemented and independently reviewed; installed acceptance passed.

Scope: add `substratebench.conditional8`, CLI task `conditional_logic_8`, focused
tests, and `examples/reuse_memory_two_tasks.py`. This is a standard-library
implementation of the mathematical contract. Existing four-bit profiles and
`carry8.py` remain byte-identical; their report contract versions remain 0.2.0
and 0.3.0. The installed package and new profile advance to 0.4.0.

The command remains the existing `carry8.Command(register, gate, value)` and
state remains eight little-endian integer bits. Gate=0 holds every bit. For
gate=1/value=0, swap q[j] and q[(j+1)%8]. For gate=1/value=1, flip q[j] and XOR
q[(j+2)%8] with OLD q[(j+1)%8]. Both changed bits use the same old state;
all other bits stay unchanged. The evaluator owns its conditional-law Gold
path: it must never call `carry8.evaluate` or `carry8._run_routes`, which hardcode
the carry law.

Reuse only demonstrated helpers: eight-bit types/Command, concrete memories,
state validation, finite interface qualification and memory calls from `carry8`;
call ledger, metrics and exclusive atomic JSON publication from `benchmark`.
Reuse `carry8.make_suite`, `sequence_id` and `permute_command` directly. Sequence
IDs identify command content and deliberately stay identical across both laws
for paired histories; `task_id` and the profile identify the law. The preserved
namespace is `sha256-carry8-width-layout-length-onehot8-gate-value-v1`, with its
existing carry8 prefix, length and command bytes. No new identity hash or suite
generator is needed. Lab uses onehot8/value/gate: convert named raw fields and
regenerate public IDs; digest-only inventories cannot be converted.

Admission checks all 256 readable states, 4096 SET operations preserving the
other seven bits, then all 8192 conditional state-command transitions. Failed
memory admission skips the source; failed source admission skips every route.
Scientific FAIL produces a writable report, null unattempted route metrics and
zero route calls. Malformed data or technical exceptions propagate as errors.
Confidence/logits/margins and batch contexts are unmeasured by this bits-only ABI.

Admitted sources run autonomous L24/L128 normal, cyclic-register-permuted,
zero-write and per-command-reset routes. The callback receives only memory's
actual read state. Gold remains evaluator-local and never enters a callback or
route write. Thresholds remain 99% prefix, 95% whole-sequence accuracy, with
at least 30 percentage points of whole-sequence loss per control and length.
Paired transformed commands are not independent holdouts; caller exclusions
cover base and transformed IDs but completeness is unverified.

The bundled exact callback is marked `reference_oracle`; the zero callback is a
control. Other callbacks are marked `caller_supplied`, with caller-declared
identity from `controller_label`; the runner does not certify training,
parameters, freezing or absence of hidden history. Optional caller-declared
source creation wall seconds are finite/nonnegative and explicitly unaudited;
missing creation time and energy stay UNKNOWN. Runner phase ledgers count actual
visible calls, not external source acquisition/training. Runner wall time excludes
installation/imports/report I/O. There is no physical clock, wait operation,
matched-time sham, calibration, cost advantage or learned-transfer claim.

The two-task example creates one `carry8.EncodedMemory` object, runs the carry
reference callback, explicitly resets that same object, then runs the conditional
reference callback. Its fixed channel/inversion parameters are reused unchanged.
It writes two ordinary independent reports and describes ABI reuse only. There
is no claimed learned transfer or combined/amortized cost measurement; the
between-task reset is example lifecycle work outside either evaluate ledger.

Boundary map:

- `conditional8` owns the new law, source admission, Gold labels, route execution
  and its versioned report; `carry8` keeps the existing memory/command owners.
- CLI only selects the concrete profile/controller/memory and writes a report.
  API callers supply fixed `next_state(bits8, Command) -> bits8` and
  `reset/read/set_bit` memory methods. No Lab imports or mandatory dependencies.
- CLI/API arguments, exclusion IDs, caller-declared metadata, callback outputs
  and memory reads are untrusted. `evaluate` validates setup inputs before calling
  supplied memory methods; CLI first constructs only bounded built-in digital
  memory. Bound episodes 2–128 even, IDs 2000000 entries and reports 16 MiB.
- Qualification intentionally prepares known states through public SET calls.
  Autonomous routes reset per episode and read/write only the supplied memory.
- Durable writes reuse `write_result`: exclusive atomic publication, no overwrite
  and temporary-file cleanup. Retrying an existing path fails without replacing it.
- Technical failures abort; scientific failures remain explicit reports. There
  are no async jobs, cancellation, mutable caches or persistent model writes.
- Implementation hashes bind conditional8/carry8/task/benchmark code. Law identity
  is `conditional_logic_8`, profile
  `conditional-logic-eight-bit-memory-reference-0.4`, report contract 0.4.0.
