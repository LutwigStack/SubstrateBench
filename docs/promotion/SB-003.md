# SB-003: bounded eight-bit carry reference profile

STATUS: implemented and independently reviewed; installed acceptance passed.

Scope: add `substratebench.carry8` and CLI task `carry_counter_8`. Existing
four-bit exports, defaults, command bytes, suite construction and reports remain
unchanged. This is an independent standard-library rewrite of the mathematical
contract, not a copy or import of Lab models, runners or evidence.

The callback receives eight little-endian integer bits and a separate
`carry8.Command(register, gate, value)`. An active command adds or subtracts
`2**register` modulo 256; gate=0 holds the complete state. Weights must be frozen
and task history must persist only in the supplied memory. Callback purity and
model freezing are caller obligations that Python cannot prove.

The new profile first checks 256 readable states, 4096 generic SET operations
that preserve the other seven bits, and all 8192 state-command transitions.
Source-law qualification is an admission gate. Failed memory or source admission
leaves long-route metrics null and route call counts zero. A bits-only callback
does not expose confidence: signed margins are not measured and are not claimed.

Admitted callbacks execute their own memory state on fresh random length-24 and
length-128 sequences. Normal and register-permuted routes must reach 99% prefix
and 95% whole-sequence accuracy. Actual zero-write and per-command-reset controls
must each lose at least 30 percentage points of whole-sequence accuracy relative
to normal at each length. These controls test visible storage dependence, not
the causal contribution of trained weights. The bundled arithmetic oracle only
validates the reference harness; its PASS is not learned-source or physical
transfer evidence.

New sequence identities use a width/layout/length-prefixed SHA256 namespace,
followed by ordered one-hot-eight/gate/value bytes. Existing four-bit IDs are
unchanged. Lab arrays order value before gate: reconstruct ordered public
commands and regenerate IDs; digest-only inventories cannot be converted.
Normative bytes are the literal prefix
`b"substratebench-carry8-sequence-v1\x00\x08onehot8-gate-value\x00"`, followed by
the four-byte unsigned big-endian sequence length and ten bytes per command.
The accepted sequence length is 1–128; `make_suite` returns the suite and unique
excluded-ID count. Report profile is
`carry-counter-eight-bit-memory-reference-0.3` and contract version is 0.3.0.
Old four-bit reports retain their original 0.2.0 contract version independently
of the installed package version.
Caller exclusions are bounded at 2000000 lowercase SHA256 entries, sufficient
for the currently known million-ID inventory, with completeness explicitly
unverified. Base and paired permuted queries are both excluded and deduplicated.
Each base and permuted sequence must include an active upper-half command;
this input-only rule is fixed before outputs are observed.

Boundary map:

- Task law, eight-bit types, concrete digital memories, qualification, suite and
  execution are owned by `carry8`; the existing four-bit owners stay intact.
- CLI parses task/controller/memory arguments and dispatches. API integrators
  supply fixed callbacks and memory methods `reset/read/set_bit`.
- CLI arguments, exclusion entries, callback outputs and memory observations
  are untrusted and validated before they cross their corresponding boundary.
- Gold state remains evaluator-local during autonomous routes; it is never sent
  to a callback or used for a route memory write. Qualification separately
  prepares prescribed known states through public writes. Routes read memory on
  each command and reset per episode.
- Durable publication reuses `benchmark.write_result`: complete JSON, 16 MiB
  limit, atomic exclusive link, no overwrite, temporary cleanup on failure.
- Costs count visible memory/controller/label calls per phase and runner wall
  time. External training, internal physical work, energy, imports and report
  I/O remain outside these measurements; external training cost is unknown.
- Invalid inputs raise errors; failed scientific admission returns a failed
  report with explicit unattempted routes. CLI keeps exit codes 0/1/2.

Acceptance completed: 31 tests passed (18 legacy and 13 eight-bit), including
complete finite-law and SET checks, autonomous rollouts, negative admission,
malformed boundaries, atomic persistence and resource bounds. Fresh noneditable
installation and installed CLI/API checks passed outside the checkout: oracle
exit 0, zero-source exit 1, invalid input/no-overwrite exit 2. The maximum
128-episode-per-length report was below the 16 MiB limit. Independent CODE and
METHOD reviews returned Ship. These are public arithmetic-reference checks;
they do not validate a learned source or physical memory transfer. Exact staged
review remains required before a local commit. No new dependencies, Lab imports,
physical simulator, pretrained weights, architecture sweep or licensing claim.
