# SB-002: carry and conditional four-bit reference tasks

STATUS: implementation and independent review in progress; not committed.

Owner: `substratebench.task.reference_step` owns the selected finite task law;
`substratebench.benchmark.evaluate` owns labels, memory qualification, paired
evaluation and costs. Memory retains all predicted task history; controller
purity and frozen weights remain explicit caller obligations.

Scope: add `carry_counter` and `conditional_logic` to the existing public digital
reference harness, preserving the default `gated_xor` law and API. All tasks use
four little-endian state bits and `Command(register, gate, value)`. The existing
six-byte public sequence identity and sampler remain unchanged. Selected task
identity is recorded in every result; the new package version is 0.2.0, with
additive task identity in the existing schema-version-1 result shape.

Evidence: the independently audited lab `carrier-task-pilot` tested both harder
laws. All four learned controllers passed their own-codec 16-state readback and
all 256 projected state-command transitions. Only the two carry controllers
passed the parent's original full-GRU learning gate; both conditional controllers
failed that gate and their native cells were not attempted. The parent's full
matrix scientifically failed. Its accepted audit record is a valid record of
that mixed outcome, not a successful full-matrix transfer. A proposed child study
uses a different canonicalized-source baseline and has no results at promotion
design time. Neither experiment's learned models, simulator or artifacts enter
this public package.

The rewrite is limited to task-law selection, reference-controller CLI wiring,
task-specific report profiles, documentation and focused finite-domain checks.
There are no lab imports, Torch dependency, hidden neural source, learned adapter,
ODE carrier, architecture framework or new cost claim. A passing bundled oracle
run checks the harness; it does not reproduce the learned-source experiments.

Identity correction: historical lab command bytes are one-hot register followed
by **value, gate**, while the public codec has always used **gate, value**. The
earlier public claim of direct historical compatibility was inaccurate for
asymmetric commands. Public digest bytes remain stable for existing callers.
To exclude historical data, reconstruct public `Command` objects from original
ordered command arrays and regenerate their public IDs. A digest-only lab ID list
cannot be converted without those arrays.

Checks planned: all 256 transitions of each new law, carry/borrow wraparound,
simultaneous conditional updates, held gates, invalid task rejection, paired
transformed Gold, existing default API regressions and installed CLI runs from
an arbitrary working directory. Independent code and methodology review is
required before committing this promotion.
